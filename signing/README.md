# Постоянный ключ подписи Android (Persistent Signing Key)

В этой папке находится постоянный криптографический ключ подписи APK для приложения **«Гарвард: Справедливость (Курс лекций)»**.

## Зачем нужен постоянный ключ в репозитории?

Операционная система Android разрешает установку новой версии приложения **поверх уже установленной** (без удаления предыдущей версии и с сохранением прогресса чтения и результатов тестов) при соблюдении двух условий:

1. **Одинаковый `applicationId` (`edu.garvard.justice.course`) и идентичный сертификат подписи APK.**
2. **Неубывающий `versionCode`** — в `app/build.gradle.kts` он рассчитывается как `100 + GITHUB_RUN_NUMBER`, поэтому каждая следующая сборка в GitHub Actions гарантированно получает больший `versionCode`, чем предыдущая.

Именно поэтому ключ лежит в открытом репозитории: любая сборка из GitHub Actions подписывается тем же самым сертификатом, что и все предыдущие, и обновление ставится «поверх» без ошибки `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

## Параметры ключа

| Параметр | Значение |
| --- | --- |
| Файл хранилища | `signing/garvard-release-key.jks` |
| Файл с параметрами | `signing/keystore.properties` |
| Формат хранилища (`storeType`) | `PKCS12` |
| Алиас ключа (`keyAlias`) | `garvard_justice` |
| Пароль хранилища (`storePassword`) | `garvard2026` |
| Пароль ключа (`keyPassword`) | `garvard2026` |
| Алгоритм | `RSA 2048 bit`, `SHA256withRSA` |
| Срок действия сертификата | до 15 марта 2054 года (10 000 дней) |
| SHA-256 отпечаток сертификата | `14:6C:D7:AF:A4:35:F8:E9:3C:05:EA:1F:92:3F:DC:F1:14:05:31:BF:9F:A8:A5:DA:68:D6:74:7F:8A:E1:94:D8` |

> ⚠️ Ключ публичный (лежит в открытом репозитории). Это осознанное решение автора проекта: оно позволяет любому форку и любой сборке Actions выпускать совместимые обновления. Не используйте этот ключ для приложений, где важна защита от подделки сторонними людьми.

## Как проверить подпись скачанного APK

```bash
# отпечаток сертификата APK
apksigner verify --print-certs garvard-justice-course.apk

# либо через keytool
keytool -printcert -jarfile garvard-justice-course.apk
```

Отпечаток `SHA-256` должен совпасть со значением из таблицы выше.
