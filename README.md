# Гарвард: Справедливость — курс лекций и Android-приложение

Проект объединяет две вещи:

1. **Полный текстовый курс лекций на русском языке** по мотивам легендарного гарвардского курса профессора **Майкла Сэндела «Justice» (Moral Reasoning 22)**.
2. **Android-приложение**, в котором этот курс упакован офлайн: 12 лекций, 10 моральных дилемм, галерея мыслителей, словарь терминов и тесты с сохранением прогресса.

Сборка APK полностью автоматизирована в **GitHub Actions**, подписана **постоянным ключом из репозитория** и устанавливается **поверх предыдущей версии** без потери прогресса.

## 📱 Android-приложение

- **Package / applicationId:** `edu.garvard.justice.course`
- **minSdk 24 · targetSdk 34 · Kotlin · AGP 8.2.2 · Gradle 8.6**
- Полностью **офлайн**: HTML-интерфейс + JSON-контент лежат в `app/src/main/assets/`.
- **Закладки и автопродолжение:** приложение открывается на той странице и том месте в тексте, где вы остановились; в лекции есть плавающая кнопка 🔖, а все закладки собраны на главном экране.
- Прогресс чтения, ответы на тесты и выбор в дилеммах сохраняются в `localStorage` WebView и **не теряются при обновлении**.
- Встроенная **проверка обновлений** через GitHub Releases (`/releases/latest`): приложение сравнивает `versionCode`, скачивает APK через `DownloadManager` и открывает системный установщик.

### Как установить

1. Откройте раздел [**Releases**](../../releases/latest).
2. Скачайте `garvard-justice-course.apk`.
3. Разрешите установку из этого источника и установите.
4. Следующая версия ставится **поверх** — без удаления и без потери прогресса.

### Как собрать локально

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## ⚙️ GitHub Actions

Workflow [`.github/workflows/android.yml`](.github/workflows/android.yml) запускается на каждый push в `main`/`arena/**`, на pull request и вручную (`workflow_dispatch`):

1. JDK 17 + Android SDK 34.
2. `./gradlew testReleaseUnitTest` — проверка целостности контента курса (`CourseDataTest`).
3. `./gradlew assembleRelease` — подпись постоянным ключом (`signing/`).
4. `apksigner verify --print-certs` — **жёсткая проверка**, что отпечаток сертификата совпадает с ожидаемым; при несовпадении сборка падает.
5. Артефакт `garvard-justice-course-<version>.apk` + `sha256`.
6. Публикация **GitHub Release** с тегом `v<versionName>` и прикреплённым APK — из него приложение и берёт обновления.

`versionCode` = номер запуска workflow, `versionName` = `1.0.<номер>`, поэтому каждая новая сборка гарантированно «старше» предыдущей и ставится поверх.

## 🔄 Как выпустить обновление

1. Внесите изменения (контент курса или код приложения).
2. Сделайте `git push` — Actions соберёт и опубликует новый релиз.
3. У пользователей приложение покажет доступное обновление и поставит его поверх старой версии.

Контент курса генерируется скриптами из папки [`scripts/`](scripts/):

```bash
PYTHONPATH=scripts python3 scripts/build_course_content.py
```

Скрипт пересобирает `course/*.md`, `COURSE_JUSTICE_HARVARD.md` и `app/src/main/assets/course_data.json`.
